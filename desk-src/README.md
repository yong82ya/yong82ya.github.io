# 문서 작업대 원본 코드

- `site-index.html` — 앱 전체 원본. Claude 버전(아티팩트)은 이 파일 그대로입니다.
- `gh/build.py` — 위 파일을 깃허브 버전(`/desk/`)으로 바꾸는 스크립트. `gh/src/`의 조각(저장소, 구글 드라이브 동기화, 제미나이 AI, 공유 받기 등)을 끼워 넣습니다.
- 빌드: `site-index.html`을 `site/index.html` 자리에 두고 `python3 gh/build.py` → `gh/desk/`에 결과가 생깁니다. 그 내용을 저장소의 `desk/`에 복사해 올리면 됩니다.

Claude 버전 주소: https://claude.ai/artifact/11Yd9qdJcCkHJpmH19voWZ
